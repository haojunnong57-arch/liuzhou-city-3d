## 1. 核心地标高度（交叉验证）

### 柳州地王国际财富中心（Diwang International Fortune Center）

| 项目 | 内容 |
|------|------|
| 地址 | 广场路 / 广场路10号一带，五星商圈 |
| 建筑高度 | **303 m**（architectural height） |
| 层数 | 地上约 72 层（部分来源写 75 层含表述差异） |
| 坐标（公开） | 约 24.3207°N, 109.4117°E（EN Wikipedia）；另有 24.3232°N, 109.4071°E（ZH Wikipedia）— 存在公开坐标差异，建模时需以 OSM 轮廓为准并标注 |
| 交叉来源 | 1) Council on Tall Buildings and Urban Habitat (CTBUH) / The Skyscraper Center<br>2) English Wikipedia: Diwang International Fortune Center（引用 CTBUH）<br>3) 中文维基百科：柳州地王国际财富中心<br>4) 百度百科相关条目（封顶/高度描述与 303 m 一致） |
| 置信度 | **高（公开建筑高度）** — 多来源一致为 303 m；层数表述略有出入，采用“约 72–75 层” |
| 许可 | 维基百科文字遵循 CC BY-SA；高度数字本身为事实性信息；使用时保留来源标注 |
| 采集说明 | 2026-11-13 检索；未使用未公开施工图 |

**注意**: 本项目中若覆盖该地标高度，标记为 `source=public_landmark_303m`，`confidence=high`。位置仍受 OSM 轮廓精度限制（米级，非 10–20 cm）。
